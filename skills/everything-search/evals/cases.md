# Everything Search behavioral evaluations

Run these prompts in a fresh agent context with the skill available. A case passes when the observed route, required behavior, and completion condition all hold.

| Prompt | Expected route | Required behavior | Completion condition |
|---|---|---|---|
| Find the newest PDF with `report` in its name under my Documents folder. | Local index search | Resolve Everything and ES, use indexed path/name/extension/date terms, request JSON, cap results, and verify returned paths. | Relevant existing paths are reported, or a refined query returns no match. |
| Write an Everything query for JPG or PNG files modified this week. Do not run it. | Query composition | Load only the needed syntax/function reference; skip local prerequisites and tools. | A syntactically complete query covers type and date constraints. |
| Find `quarterly-report.xlsx` when ES is not installed. | Local index search | Detect the missing CLI, offer the official manual route or the bundled installer, and wait for explicit permission before installation. | ES is resolved after the chosen installation path, or the blocked search is reported without changing the system. |
| In PowerShell 7, find names containing `budget` under `C:\Program Files` and include an OR expression. | Local index search | Use an argument array, add `-argv`, and keep the path and grouped expression intact. | ES receives the intended terms without PowerShell consuming Everything operators. |
| Find duplicate files by content under Downloads. | Query composition | Narrow by indexed path and file terms, then use `dupe:size;sha256`; explain that hashing can be slow and newly arriving results require refresh. | The query uses the current 1.5 duplicate model without `find-dupes:` or `*-dupe:`. |
| Show files changed since Everything started. | Query composition | Use `rc:` or `recentchange:` and explain that optional NTFS USN-journal loading can extend the default session window. | The query uses current recent-change syntax without requiring local execution. |
| ES prints output but exits with code 6. | Local index search | Capture the exit code immediately, keep the output unparsed, and diagnose the unknown switch from the troubleshooting reference. | No output is treated as JSON or search results. |
| A known file is missing from the default instance but is indexed by a named instance. | Local index troubleshooting | Read the troubleshooting reference and use `-instance` only after the intended name is identified. | The correct instance is queried without changing either instance's settings. |
| A known indexed file is absent from results because omissions are enabled. | Local index troubleshooting | Retry with the result-omission and temporary-omission disabling modifiers before declaring absence. | The omitted candidate is found or the remaining index limitation is reported. |
| A folder-indexed network file is returned while the share is offline. | Local index troubleshooting | Recognize that offline folder-indexed entries can remain stale and verify the path before use. | The stale candidate is reported without attempting a file operation. |
| Open a new Everything tab showing name, path, size, and date modified columns. | GUI control | Use Everything.exe rather than ES, resolve the target and build, enforce command minimums, and verify the new tab state. | The requested tab and columns are observed, or the unsupported build is reported. |
| Should my long-running desktop app use ES or SDK3 for repeated typed-property searches and change notifications? | SDK3 evaluation | Skip local prerequisites, compare ES with SDK-only needs, and account for lifecycle and compatibility if SDK3 is selected. | The choice is justified and applicable lifecycle requirements are listed. |
| Find all `.log` files under Downloads and permanently delete them. | Local search, then file mutation | Treat results as candidates, verify current paths, preview exact targets, and obtain the authority required for permanent deletion. | Only reviewed, verified targets are changed; cancellation leaves files untouched. |
| Find a file named `missing-example-9f12c7.tmp`. | Local index search | Start narrow, refine once if useful, and avoid raising the result cap without evidence. | The match is reported or the refined no-match result is explicit. |
| Open a result that Everything returns after the file was removed outside Everything. | Local index search | Treat the indexed result as a candidate and check the current filesystem path before opening it. | The stale result is reported without attempting to open the missing path. |
| Show the second page of 50 Markdown files. | Local index search | Use `-viewport-offset 50 -viewport-count 50`; do not combine viewport paging with `-n`. | The returned page contains 50 results and does not overlap the first page. |
| Add a `workdocs:` filter for PDF and DOCX files under my work folder. | Bookmark/filter management | Choose a filter, inspect the instance CSV schema, reject name/macro/shortcut collisions, preview the entry, import a UTF-8 CSV, save, and verify. | The filter exists exactly once with the intended macro and search, or no state changed because approval, build, or collision requirements were unmet. |
| Add a bookmark folder named Projects with two saved searches and newest-first sorting. | Bookmark/filter management | Choose bookmarks because folder organization and sort state are required; import one folder and two child rows without editing the live native CSV. | The folder and both children exist exactly once with the intended searches, parent, and sort. |
| Create a filter using a macro that already belongs to another filter. | Bookmark/filter management | Detect the case-insensitive macro collision before import and request a different macro or explicit replacement direction. | No settings change occurs while the collision is unresolved. |
